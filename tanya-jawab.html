Panduan Resmi TW-Mapper

Jawaban resmi untuk pertanyaan teknis, ketentuan lisensi, dan operasional lapangan.

9 Topik Terverifikasi
1. Lisensi TW-Mapper berlaku untuk berapa perangkat (Paket Hobby vs Paket Pro)?

Ketentuan resmi jumlah perangkat aktif:

  • Paket Hobby: Berlaku resmi untuk 2 perangkat aktif bersamaan (misalnya 1 unit remote controller layar dan 1 unit smartphone Android cadangan).
  • Paket Pro: Berlaku resmi untuk 2 perangkat aktif bersamaan (misalnya 1 unit remote controller DJI RC 2 / RC Pro dan 1 unit smartphone Android cadangan) untuk fleksibilitas kerja di lapangan.

2. Apakah TW-Mapper bisa membuat misi otomatis dari berkas KML, atau harus menggambar manual?

Bisa otomatis penuh di Paket Hobby maupun Paket Pro.

Anda tidak perlu menggambar batas lahan manual di layar remote. Cukup impor berkas batas area berformat KML, aplikasi akan langsung membuat kisi jalur terbang (flight grid), heading kamera, dan overlap secara otomatis.

Seluruh parameter penerbangan juga bisa diatur ulang di TW-Mapper (seperti ketinggian terbang, kecepatan jelajah, interval foto kamera, dan persentase overlap foto).

Pada Paket Pro, mendukung multi-boundaries banyak blok lahan sekaligus serta kontur elevasi Follow Terrain (mengikuti kontur elevasi bukit/lembah berbasis DEM).

3. Apakah fitur Flash Inject (Injeksi Tanpa Dummy) tersedia di semua lisensi dan mengapa butuh TW Tweaks / DJI Fly Mod?

Ya, fitur Flash Inject (Injeksi Tanpa Dummy) didukung di semua lisensi TW-Mapper (Paket Hobby maupun Paket Pro). Fitur ini mentransfer rute waypoint secara instan langsung ke direktori sistem DJI Fly tanpa perlu repot menyiapkan berkas dummy manual.

Mengapa Flash Inject Membutuhkan Modul TW Tweaks / DJI Fly Mod?

Flash Inject bekerja dengan berkomunikasi langsung ke sistem internal DJI Fly di remote controller atau smartphone. Oleh karena itu, perangkat Anda membutuhkan modul TW Tweaks / DJI Fly Mod sebagai jembatan sistem agar injeksi instan (< 1 detik) dapat berjalan mulus.

  • Paket Pro: Sudah include (termasuk) lisensi TW Tweaks / DJI Fly Mod langsung di dalam paket, sehingga fitur Flash Inject langsung aktif siap pakai.
  • Paket Hobby: Fitur Flash Inject didukung oleh aplikasi, namun pada Paket Hobby belum include lisensi TW Tweaks (jika menggunakan metode modul TW Tweaks / DJI Fly Mod, modul tersebut memerlukan lisensi/aktivasi terpisah, atau Anda dapat memanfaatkan opsi injeksi Shizuku di smartphone Android tanpa biaya lisensi tambahan).

Cara Mengaktifkan: Buka menu Pengaturan (Settings) di dalam aplikasi TW-Mapper, lalu pilih opsi koneksi "DJI Fly MOD" (atau opsi Shizuku). Seluruh rute waypoint akan langsung terinjeksi otomatis ke sistem remote dalam hitungan 1 detik.

4. Bagaimana alur injeksi rute jika menggunakan smartphone Android (Remote Seri RC-N1 / RC-N2 / RC-N3)?

Untuk pengguna smartphone atau tablet Android dengan remote DJI seri RC-N, TW-Mapper menyediakan dua pilihan alur injeksi yang sangat fleksibel:

  1. Metode Flash Inject (TW Tweaks / DJI Fly Mod): Membutuhkan instalasi modul DJI Fly Mod (TW Tweaks) pada smartphone Anda. Cukup pilih opsi koneksi "DJI Fly MOD" di pengaturan TW-Mapper, dan rute misi terbang langsung terinjeksi instan kurang dari 1 detik tanpa berkas dummy.
  2. Metode Shizuku Direct Inject: Memanfaatkan modul pendukung Shizuku (tanpa perlu root). Cukup pastikan layanan Shizuku aktif, tekan tombol "Injeksi Misi KMZ", dan berkas rute WPML langsung ditransfer ke direktori internal DJI Fly dalam hitungan 1 detik.

7. Apakah aplikasi TW-Mapper membutuhkan koneksi internet saat terbang di lapangan?

Tidak membutuhkan internet saat di lapangan.

TW-Mapper didesain 100% mandiri untuk penggunaan lapangan secara luring (offline). Selama Anda telah mengunduh data cache citra satelit area kerja sebelumnya saat berada di basecamp atau hotel, remote dan drone dapat menjalankan seluruh proses perencanaan hingga eksekusi misi tanpa memerlukan kuota internet maupun sinyal seluler di remote area.

100% Offline Cache Citra Satelit Remote Area

8. Apakah perlu melakukan modifikasi fisik atau rooting pada drone maupun remote?

Sama sekali tidak.

Drone dan remote controller Anda tetap 100% berstatus original standar pabrik. Tidak ada pembongkaran perangkat keras (hardware), tidak ada modifikasi firmware yang membahayakan, dan seluruh sistem remote tetap aman.

9. Mengapa slider kecepatan drone (speed) dibatasi otomatis dan tidak bisa dinaikkan maksimal?

Sistem TW-Mapper mengaktifkan proteksi cerdas Dynamic Speed Clamping.

Fitur ini menghitung batas kecepatan terbang aman berdasarkan ketinggian terbang, persentase overlap, dan interval buka-tutup rana kamera (terutama pada resolusi 48 MP). Kecepatan disesuaikan otomatis agar kartu memori MicroSD drone sempat memproses dan menyimpan file foto, mencegah risiko foto terlewat atau tidak terekam (anti foto bolong).
